# CANDY COOKIE CHOCOLATE — motion clip

HTML/Canvas клип на трек **«キャンディークッキーチョコレート» — 初音ミク・重音テトSV**.
Всё работает локально, без интернета и без установки: графика рисуется в реальном времени,
звук встроен в страницу.

## Как запустить

1. Откройте `index.html` двойным щелчком в Chrome или Edge.
2. Нажмите **PLAY CLIP** — это нужно, чтобы браузер разрешил звук.
3. Для полного экрана нажмите **F** (или кнопку в правом нижнем углу).

Можно открыть и через локальный сервер:

```powershell
cd C:\Users\yungspider\Desktop\candy
python -m http.server 8765 --bind 127.0.0.1
```

и зайти на `http://127.0.0.1:8765/`.

## Управление

| Действие | Клавиша / элемент |
| --- | --- |
| Пауза / продолжить | `Space` или клик по кадру |
| В начало | `R` |
| Перемотка ±5 сек | `←` / `→` |
| Перемотка по треку | клик или перетаскивание по полосе внизу |
| Звук вкл/выкл | `M` |
| Полный экран | `F` |
| Повтор после финала | кнопка `↺ REPLAY` |

## Синхронизация с вокалом

- Нарезка сцен идёт не по тактам, а по **фразам вокала**: каждая новая строка/выкрик
  получает свой монтажный кусок за 0.03–0.08 с до первого слога.
- Внизу идёт караоке-карточка: японская строка с прогрессивной заливкой и русский перевод.
- В интро, хуке и быстрых «CAN CHO / COO KIE / LATE» карточка отключается — там вместо неё
  гигантские слова, которые меняются на каждый слог.
- Для частушек «限界 / 極彩 / 大喝采» отдельная сцена `CHANT` с огромными иероглифами.
- Тайминги сверены по сетке битов (172.27 BPM) и официальным ручным субтитрам RU/EN.

## Что внутри

- `index.html` — страница, HUD, стартовый экран.
- `style.css` — оформление интерфейса и адаптив.
- `engine.js` — canvas-движок, типографика, конфетная графика, таймлайн, Web Audio,
  караоке-карточка и монтаж из 53 кусков.
- `lyrics.js` — 75 таймированных строк: японский оригинал, русский перевод, типы сцен.
- `scenes1.js` … `scenes4.js` — базовые сцены: обложка, башня, кольцо, упаковка, глитч и т.д.
- `scenes5.js` — lyric-driven сцены: данго-башня, открытая коробка, бинарность,
  спрятанная «C» и гигантские слова.
- `analysis.js` — сетка битов (172.27 BPM), энергия, waveform.
- `track.js` — MP3 в base64, чтобы `file://` работал без CORS и сервера.
- `track.mp3` — исходный аудиофайл (для замены/пересборки).

## Технически

- Кадр 1920×1080, вписывается в окно с сохранением 16:9.
- 53 монтажных куска; смена — по фразам вокала, внутри сцен движение реагирует на бит.
- Длительность: 2:44, первый бит ≈ 0.49 с, BPM ≈ 172.27.
- Аудио декодируется через Web Audio API из встроенного base64.
- Прогресс, waveform и маркеры актов строятся из предварительного анализа.

## Если что-то не так

- **Нет звука** — проверьте вкладку браузера (не muted), громкость системы и нажмите `M`.
- **Пустой экран** — убедитесь, что рядом с `index.html` лежат `analysis.js`, `track.js`,
  `lyrics.js`, `engine.js` и `scenes1-5.js`.
- **Автозапуск заблокирован** — просто нажмите PLAY CLIP ещё раз; браузеры требуют жест
  пользователя для старта аудио.
