Откройте index.html в Chrome или Edge. Сервер и интернет не требуются.

Звук, графика и субтитры встроены в HTML (track.js / analysis.js / lyrics.js).

СИНХРОНИЗАЦИЯ
Начала строк посажены на вокальные атаки (допуск ±0,34 с, сдвиг до 0,3 с),
слова внутри строки распределены по слогам. Подсветка идёт по словам.
Кадр меняется на слове: «двадцать первое лето» — зима уходит в лето,
«могут съесть даже планету» — на слове «планету» появляется планета с укусом.

УПРАВЛЕНИЕ
Пробел: пауза. ← →: ±5 с. F: полный экран. M: звук. R: в начало.
Клик по кадру — пауза. Полоса снизу — перемотка.
